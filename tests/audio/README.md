# Prerecorded human speech fixture

`Sakartvelo.ogg`: pronunciation of საქართველო by Wikimedia Commons user **Kober**, 2009. Author released it into the public domain.

Source and attribution: https://commons.wikimedia.org/wiki/File:Sakartvelo.ogg
Original: https://upload.wikimedia.org/wikipedia/commons/2/2a/Sakartvelo.ogg
Unmodified file; original source metadata retained in `Sakartvelo.source.json`.

This is a public, prerecorded human pronunciation used to diagnose model behavior. It is not a live participant microphone trial, learner test result, or validated Georgian-ASR benchmark. The reference word is held for evaluation only and is never passed to the recognizer. Initial failures are in `docs/human-audio-model-comparison.json`; the selected model's result is in `docs/georgian-model-comparison.json` and `docs/final-audio-smoke-results.json`.
